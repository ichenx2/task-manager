# Web App 個人課堂實作：任務管理器

## 網站連結

- 原生版（HTML / CSS / JavaScript）：https://ichenx2.github.io/task-manager/
- React 版：https://ichenx2.github.io/task-manager/react/

## 功能

- 新增任務
- 查看任務
- 完成任務
- 刪除任務
- 篩選任務
- 在不同螢幕尺寸下正常使用

## 檔案結構

- `index.html`、`style.css`、`script.js`：原生版
- `react/index.html`、`react/app.jsx`：React 版
（兩個版本共用 `style.css`）
